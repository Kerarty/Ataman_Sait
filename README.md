# Атаман — сайт барбершопа в Светлогорске

Делаю сайт для барбершопа «Атаман» (Чёрный барбер) — ул. Интернациональная, 24, г. Светлогорск,
Гомельская область.

## Зачем это

У барбершопа нет своего сайта. Он есть только в агрегаторах (Яндекс Карты, jsprav.ru) и в
Instagram. Запись идёт через Viber и звонок, расписание надо помнить наизусть, а свободные слоты
не видно заранее — из-за этого часть клиентов просто не доходит.

Сайт должен решить три задачи:

- **Показы.** «Барбершоп Светлогорск», «мужская стрижка Светлогорск», «борода Светлогорск» —
  запросов достаточно, конкурентов в городе всего около десяти.
- **Запись.** Человек сам выбирает услугу, мастера и время, без звонка.
- **Загрузка.** Фото мастеров и витрина работ вместо абстрактных обещаний.

## Что уже есть

### Прототип дизайна

`prototype/index.html` — кликабельная главная страница. Один файл, без сборки: открыл в браузере
и смотришь. Внутри:

- тёмная красно-чёрная тема в цветах логотипа
- услуги с ценами в четырёх категориях
- карточки мастеров с телефонами
- галерея работ на реальных фотографиях салона
- **рабочее окно онлайн-записи** — услуга → мастер и дата → время и контакты → подтверждение
- блок контактов с часами работы и ссылкой на Яндекс Карты
- мобильная версия и меню

Посмотреть: открой `prototype/index.html` в браузере. Или поднять сервер:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

и зайди на `http://127.0.0.1:8765/index.html`.

### План работ

`PLAN.md` — разведка по барбершопу, выбор стека, модель данных, этапы, риски и бюджет.

## Стек

Прототип — чистый HTML/CSS/JS, чтобы быстро согласовать внешний вид.

Продакшн планируется на:

| Слой | Технология |
|---|---|
| Фреймворк | Next.js 15 (App Router) + TypeScript |
| Стили | Tailwind CSS 4 |
| База | PostgreSQL 16 + Prisma |
| Аутентификация | Auth.js, роли владельца и мастера |
| Уведомления | Telegram Bot API |
| Деплой | Docker Compose + Caddy на VPS в Беларуси |

VPS в Беларусии, а не зарубежный хостинг — чтобы оплата шла в BYN и не было проблем с картами.
Подробности и альтернативы — в `PLAN.md`.

## Данные о барбершопе

Проект на старте опирался на открытые источники — это черновик, который нужно подтвердить у
владельца:

- Яндекс Карты, карточка ID `16749652973`
- Instagram `@ataman_barbershop_svt`
- jsprav.ru, pro-barbershop.ru

Что точно известно: адрес, два телефона, два мастера (Александр и Кастусь), рейтинг 4,9,
23 отзыва, режим работы вт/ср/пт/сб 09:00–21:00.

Что требует подтверждения: **полный прайс** (в открытых источниках нашлась только одна позиция —
мужская стрижка 35 BYN), расписание (источники противоречат друг другу) и фотографии мастеров.

Фотографии в `prototype/assets/` взяты из открытой ленты Instagram барбершопа и используются как
демо-контент. Перед запуском их нужно заменить на согласованные с владельцем.
