## 2. Рекомендация по стеку

### 2.1. Выбор

| Слой | Технология | Почему |
|---|---|---|
| Фреймворк | **Next.js 15 (App Router)** + TypeScript | SSR/SSG из коробки → SEO. Фронт и бэк в одном проекте, одна кодовая база, один деплой |
| Стили | **Tailwind CSS 4** + shadcn/ui | Быстрая вёрстка, готовая админка, нет зависимости от чужой платформы |
| БД | **PostgreSQL 16** | Надёжные транзакции — критично против двойного бронирования |
| ORM | **Prisma** | Чистые типы, читаемые миграции |
| Аутентификация | **Auth.js (NextAuth v5)** + сессии в БД, роли OWNER / BARBER | Стандарт, безопасные httpOnly-cookie |
| Валидация | **Zod** | Единая схема для клиента и сервера |
| Уведомления | **Telegram Bot API** | Бесплатно, работает из РБ, мастера уже используют мессенджеры |
| Деплой | **Docker Compose + Caddy + VPS в РБ** | Caddy сам выдаёт и обновляет SSL — меньше ручной работы |

### 2.2. Почему не другие варианты

| Вариант | Почему отклонён |
|---|---|
| WordPress + Elementor | Админка для мастеров в WP — хрупкая и неудобная; регулярные обновления ломают вёрстку; сложнее сделать слоты с защитой от двойной записи |
| React (Vite) SPA | Требует отдельный бэкенд → два деплоя, и SEO требует отдельной возни (пре-рендер). Для локального бизнеса с SEO «барбершоп Светлогорск» — лишний риск |
| Чистый HTML/CSS/JS | Не потянет админку с расписанием и защиту от гонки бронирований |
| SQLite | Только для MVP-записи без продакшена; миграция на Postgres позже дороже, чем начать с неё |
| Next.js на Vercel | Требует карту для оплаты; белорусские карты на международных сервисах не проходят. Плюс хостинг зарубежный → пинг |

### 2.3. Хостинг

Виртуальный сервер **в Беларуси** — оплата в BYN, низкий пинг для локальной аудитории, нет санкционных проблем:

| Провайдер | От | Примечание |
|---|---|---|
| hb.by | ~45 BYN/мес | Один из самых дешёвых, даёт SSL под ключ |
| mhost.by | — | Серверы в Минске |
| hostpro.by | — | NVMe-диски |
| Beltelecom.by | — | Нацоператор, стабильно |
| cloud.mts.by | — | Облачный |

**Рекомендация:** VPS 2 vCPU / 4 GB RAM / 40 GB NVMe — с запасом под Next.js + PostgreSQL.
+ **Домен** `.by` (≈30–50 BYN/год) или `.com`.

### 3.2. Админка

| # | Раздел | Возможности |
|---|---|---|
| 1 | Вход | Email + пароль, роли: владелец (всё) и мастер (своё расписание) |
| 2 | Расписание дня | Список записей на день с временем, клиентом, услугой, телефоном |
| 3 | Заявки | Подтвердить / отклонить / отменить / перенести. Фильтры по статусу и дате |
| 4 | Мой график | Рабочие дни, часы, перерывы, выходные, отпуска, блокировки дат |
| 5 | Услуги | CRUD, цены, длительность, категории |
| 6 | Галерея | Загрузка фото, модерация → публикация на сайте |
| 7 | Мастера | CRUD, привязка Telegram ID для уведомлений |
| 8 | Отзывы | Импорт с Яндекс Карт, модерация, публикация |
| 9 | Статистика | Количество записей, выручка, популярные услуги, загрузка по дням |

### 3.3. Ключевая бизнес-логика

- **Статусы записи:** `NEW → CONFIRMED → COMPLETED` / `DECLINED` / `CANCELLED` / `NO_SHOW`
- **Защита от двойного бронирования:** уникальный индекс на `(barberId, startsAt)` + транзакция в БД. Это главный технический риск, решается на уровне СУБД, а не фронтенда.
- **Валидация слота:** запись возможна только если мастер работает в этот день/час, слот не занят, запись не раньше текущего времени.
- **Уведомления:** бот пишет мастеру сразу при заявке; клиенту — при подтверждении; обе стороны получают ссылку на отмену/перенос.
- **Источник трафика:** каждая запись помечается источником (сайт / Instagram / звонок) — видно, что даёт денег.

## 6. Дизайн-направление

**Позиционирование:** «Атаман» — мастерская бороды и стрижки в Светлогорске. Спокойная мужественность, без пафоса.

**Бренд подтверждён.** Логотип — стилизованная красная «А» с подписью «ЧЁРНЫЙ БАРБЕР» на чёрном фоне. Отсюда палитра и тон: красно-чёрный, контрастный. Светлые стены салона и деревянный пол видно на реальных фотографиях — тёмная оболочка сайта работает как рамка для светлых снимков.

| Элемент | Решение |
|---|---|
| Палитра | Чёрный `#0a0a0c`, акцент — красный `#e01e26` (взята из логотипа) |
| Стиль | Тёмный, минималистичный, индустриальный |
| Шрифты | Заголовки: condensed uppercase (Oswald / Bebas Neue). Текст: Inter / Manrope |
| Фото | Крупные планы деталей: бритва, кисти, текстура кожи, фактура волос |
| Анимации | Сдержанные: плавное появление, параллакс фоновых фото |
| Mobile-first | ~80% трафика — с телефона |

**Адаптация под аудиторию:** окрашивание, маникюр и депиляция должны быть представлены наравне с барбер-услугами — иначе женская часть клиентов решит, что «это не про них», и уйдёт.
